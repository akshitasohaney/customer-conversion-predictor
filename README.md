
# Customer Conversion Predictor

## Overview

This project aims to predict whether a user will convert based on demographic, behavioral, and marketing-related features. The problem is formulated as a binary classification task where:

- 1 = Converted
- 0 = Not Converted

A Logistic Regression model was developed using data preprocessing, feature scaling, and categorical feature encoding to generate predictions for unseen users.

---

## Problem Statement

Given user-level information such as age, income, browsing behavior, traffic source, and purchase history, the objective is to predict whether a user will complete a conversion action.

The model is trained on historical customer data and evaluated using classification metrics before generating predictions for the final test dataset.

---

## Dataset Description

The dataset contains anonymized user information with the following features:

| Feature | Description |
|----------|------------|
| User_ID | Unique identifier for each user |
| Age | Age of the user |
| Income | Estimated annual income |
| City_Tier | City classification |
| Device_Type | Device category |
| Traffic_Source | Source through which the user arrived |
| Pages_Viewed | Number of pages viewed |
| Products_Viewed | Number of products viewed |
| Time_On_Site | Session duration |
| Previous_Purchases | Historical purchases |
| Discount_Seen | Whether a discount was shown |
| Browser_Version | Browser version identifier |
| Campaign_Code | Marketing campaign identifier |
| Converted | Target variable |

## Data Preprocessing

The following preprocessing steps were performed:

1. Missing values handled using median imputation.
2. Categorical features encoded using Label Encoding.
3. Numerical features standardized using StandardScaler.
4. User_ID removed during model training.

---

## Model Used

### Logistic Regression

Logistic Regression was selected as the baseline classification model due to:

- Simplicity
- Interpretability
- Efficiency on tabular datasets
- Strong performance for binary classification tasks

Model Parameters:

```python
LogisticRegression(
    max_iter=1000,
    random_state=42
)
```

---

## Evaluation Metrics

The model was evaluated using:

- Accuracy Score
- Precision
- Recall
- F1 Score
- ROC-AUC Score
- Confusion Matrix

The competition ranking is based on the F1 Score obtained on the hidden labels of the private test dataset.
